# METHODS LOG —— 方法论修订日志

本文件记录实验协议的全部重大修订,包括每次修订如何改变结论。
目的:(1) 让结果的可复现性可审计;(2) 记录 benchmark 设计的敏感性,
供后续研究者参考。

---

## 修订 1:FED 模型从简化线性式 → ISO 13571

**旧协议**:每步 `fed += 0.15 × smoke`(未校准的线性累积)
**新协议**:ISO 13571 分项剂量积分
- CO 当量浓度 `X_CO = 1200 × smoke` ppm(依据 Purser & McAllister, SFPE Handbook)
- 失能剂量 35000 ppm·min;每步暴露 3 s(0.05 min)
- 校准常数 K=5 → 浓烟(s≈0.86)滞留约 40 步 ≈ 2 分钟失能

**为什么改**:旧式的失能窗口被人为压窄,直接夸大了策略间差距
(见修订 3 的教训)。

**对结论的影响**:targeted vs fixed 的表观差距从 +17 点缩至 +3 点,
显著性消失(p=0.15)。

## 修订 2:修复 FED 双重计费 bug

**问题**:多个实验脚本(`_v2_main.py`、`_spreadfire_full.py`)在 harness 层
自行加算 FED,而 `env.step()` 内置的 ISO 公式也在加算 → **双重计费**,
失能速度约为设计值的两倍。

**发现方式**:显著性检验结果异常(targeted 全不显著)→ 反查数据链 →
发现两处独立 FED 来源。

**修复**:删除所有 harness 层加算,统一为 `env.step()` 内置单一来源。

**教训**:当环境的物理模型封装在 `step()` 内时,harness 层不应再触碰
任何状态变量;所有状态演化必须有唯一代码路径。

## 修订 3:从随机游走 → 系统性区域搜索

**旧协议**:不知道出口的 agent 每步随机游走。
**问题**(对抗性自审发现):随机游走 + 无生存压力使低开销段的差异退化为
"出口信息传播速度竞赛",而非调度质量差异——targeted 的表观优势被
人为放大。

**修复**:未知出口的 agent 执行系统性扫描(方向性搜索);同时给场景
加入校准的 FED 生存压力。

**教训**:测量"通信的价值"时,必须保证两条件下的导航能力严格相同,
否则通信效应与导航效应混叠。

---

## 修订 4:主场景加入起点分散

**旧协议**:所有 agent 起点集中在一列。
**问题**:通信拓扑人为稠密(全员互为邻居),targeted 的"定向"优势
部分来自"一列恰好全被罩住"的几何巧合。

**修复**:起点分散到四个象限。

## 修订 5:种子数从 30 → 52

**依据**:功效分析(Cohen d=0.55 → n≈52/臂,power=0.8, α=0.05)。
30 种子时部分对比处于功效边缘。
